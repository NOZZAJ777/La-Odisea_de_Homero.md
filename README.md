# La Odisea

**Homero** · versión en prosa en español, reestructurada en Markdown para leerla cómodamente en GitHub.

24 cantos · ~118.573 palabras · ~9 h de lectura en total, repartidas en sesiones de 15–35 min por canto.

## Cómo leerla

- Cada canto es un archivo independiente dentro de [`cantos/`](cantos/), con enlaces **← anterior / Índice / siguiente →** arriba y abajo.
- Los números en superíndice (<sup>11</sup>) son la numeración de versos del original, útil para ubicarse o citar un pasaje.
- Puedes enlazar a un verso exacto agregando `#v<número>` a la URL, por ejemplo `cantos/01-concilio-de-los-dioses.md#v44`.
- En GitHub, el botón de esquema (☰) arriba a la derecha del archivo muestra el contenido del canto.
